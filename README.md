# Basic Sales Summary from SQLite Database with Python

This project contains a Python script (`sales_summary.py`) that performs a basic analysis of sales data stored in a SQLite database (`sales_data.db`).

## Project Overview

The goal of this project was to:

1.  **Create a SQLite Database:** Generate a small SQLite database file named `sales_data.db` with a single table called `sales`.
2.  **Query Sales Data:** Use SQL within the Python script to retrieve and summarize sales information, specifically calculating the total quantity sold and the total revenue per product.
3.  **Display Results:** Present the summarized data in two ways:
    * As a text-based table in the console using the `print` function and the `pandas` library.
    * As a simple bar chart visualizing the total revenue for each product using the `matplotlib` library.

## Files in this Codebase

* `sales_summary.py`: The Python script containing the code to connect to the database, query the data, and display the results.
* `sales_data.db`: The SQLite database file (will be created if it doesn't exist when the script is run).

## How to Run the Script

1.  **Ensure Python is installed** on the system.
2.  **Install the required libraries:** If not already present, install `pandas` and `matplotlib` using pip:
    ```bash
    pip install pandas matplotlib
    ```
3.  **Save the `sales_summary.py` file** to the local machine.
4.  **Navigate to the directory** where the file was saved in the terminal or command prompt.
5.  **Run the script** using the Python interpreter:
    ```bash
    python sales_summary.py
    ```
    or
    ```bash
    python3 sales_summary.py
    ```

## Output

When the script is executed, we will observe:

* Text output in the console showing a table with the total quantity sold and total revenue for each product.
* A separate window displaying a bar chart where each bar represents a product, and the height of the bar indicates the total revenue generated by that product.

## Notes

* The `sales_data.db` file will be automatically created (if it doesn't exist) and populated with sample data by the script.
* The `sales_data` list in the script can be modified to add or change the initial sample sales data.
* The SQL query can be adjusted to perform different analyses on the sales data.
